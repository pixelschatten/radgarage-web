# Radgarage

Landingpage mit Warteliste für die App Radgarage (https://radgarage.app).

Statische Seite für GitHub Pages: `index.html`, `danke.html` (nach Bestätigung der Anmeldung), Schrift Manrope selbst gehostet (`fonts/`, SIL Open Font License), Screens in `img/`.

`werkbank/`: nicht verlinkte Katalogpflege für freigeschaltete Konten (Tabelle `katalog_helfer` in Supabase, Rollen superadmin/admin/support/helfer, Rechte über `meine_rolle()`; Tabs und Knöpfe per `data-recht` im HTML), mit `noindex`. Anmeldung mit E-Mail-Code oder Passwort (im Tab „Konto“ setzbar) plus zweitem Faktor (TOTP), Sitzung nur im Tab (sessionStorage). Nutzt die Server-Funktionen aus `supabase/katalog-helfer.sql` im App-Repo (`helfer_rolle`, `katalog_rad_erfassen`, `katalog_offen`, `katalog_freigeben`, `helfer_liste`, `helfer_setzen`, `katalog_aehnliche`, `rad_details`, `katalog_rad_ergaenzen`, `katalog_ergaenzungen_offen`, `katalog_ergaenzung_freigeben`, `katalog_teil_anlegen`, `katalog_teil_ean`, `katalog_teil_ean_weg`, `katalog_rad_aendern`, `katalog_teil_aendern`, `katalog_teile_zusammenfuehren`, `katalog_baustellen`, `katalog_uebersicht`, `katalog_verlauf`, `konten_liste`, `konto_premium`, `konto_sperren`, `konto_loeschen_admin`, `konto_dokumente_freigeben`, `konto_2fa_zuruecksetzen`, `wiederherstellung_erzeugen`, `wiederherstellung_status`, `wiederherstellung_einloesen`, `meine_sitzungen`, `meine_sitzung_beenden`, `faktor_umbenennen`, `werkbank_statistik`, `app_vorschlaege_offen`, `app_vorschlaege_erledigen`, `werkbank_system`, `shop_speichern`, `shop_loeschen`, `shops_sortieren`, `katalog_rad_loeschen`, `katalog_teil_loeschen`), die Rolle und zweiten Faktor selbst prüfen. Nach Änderungen an `werkbank/werkbank.js` die Versionsangabe `?v=` im Script-Tag in `werkbank/index.html` hochzählen, sonst laden Browser die alte Datei aus dem Cache. `werkbank/zxing.js` ist @zxing/library 0.21.3 (UMD, MIT) für den Kamera-Scan. `werkbank/supabase.js` ist supabase-js 2.118.0 (UMD, MIT), lokal abgelegt statt über ein CDN.

`anleitungen/` und `raeder/`: öffentliche Seiten für die Google-Suche, eine Seite pro Wartungsarbeit bzw. pro Rad aus dem Katalog (plus Seiten je Marke). Nicht von Hand bearbeiten: Anleitungen stehen in `_quellen/anleitungen.py`, die Räder kommen aus `_quellen/katalog-auszug.json` (erzeugt mit der Abfrage `_quellen/katalog-auszug.sql` in Supabase). `python3 _quellen/bauen.py` baut alle Seiten, `css/seiten.css` (aus `_quellen/basis.css`, `anleitungen-extra.css`, `raeder-extra.css`) und `sitemap.xml` neu. Videos laden erst nach Klick über youtube-nocookie.com (`anleitungen/video.js`), dafür in der Anleitung das Feld `video` mit der YouTube-ID füllen. Auf jeder Radseite steht das Formular „Stimmt etwas nicht?“ (`raeder/vorschlag.js`, Quelle `_quellen/vorschlag.js`): schreibt ohne Anmeldung in `vorschlaege` (art `korrektur`, `daten.herkunft = 'website'`), gebremst vom Trigger `vorschlag_bremse`. Die Werkbank zeigt diese Hinweise unter Freigaben im Reiter „Von der Website“. Ordner mit `_` veröffentlicht GitHub Pages nicht.
