    Häufige Fragen zum Trance X Advanced E+ Elite 0

    Welche Bremsbeläge passen an das Trance X Advanced E+ Elite 0 (2025)?

    Ab Werk sind SRAM Bremsbeläge Code/DB8 organisch verbaut (für SRAM Code (ab 2011), DB8, Guide RE). Die Beläge haben wir aus der Bremse erschlossen, schau beim Kauf kurz auf deine Bremse.

    Welche Kette braucht das Trance X Advanced E+ Elite 0 (2025)?

    Eine 12-fach-Kette. Ab Werk ist SRAM XX Eagle Transmission Kette (T-Type) montiert. Als Ersatz passen laut Katalog auch SRAM Eagle 70 Transmission Kette (T-Type) und SRAM GX Eagle Transmission Kette (T-Type). Mehr zur Schaltgruppe: SRAM XX Eagle AXS Transmission 12-fach.

    Welche Reifengröße hat das Trance X Advanced E+ Elite 0 (2025)?

    61-622 nach ETRTO: 61 mm breit, Felge 622 mm, im Laden meist 28 bzw. 29 Zoll (700C) genannt. Ab Werk: Maxxis Dissector EXO TR 29 x 2.40 WT. Hinten: Maxxis Rekon EXO TR 27.5 x 2.40 WT (ca. 61-584). Wie die Angaben zusammenhängen, steht in der Übersicht der Reifengrößen.

    Welcher Schlauch passt in das Trance X Advanced E+ Elite 0 (2025)?

    Schlauch 29 × 2,1–2,4 (54–62-622, passt auch für 28 Zoll × 2,0–2,4; Ventilart und -länge am Rad prüfen). Die Reifen sind tubeless-fähig. Ein Ersatzschlauch gehört trotzdem ins Pannenset.

    Welcher Motor und Akku stecken im Trance X Advanced E+ Elite 0?

    Verbaut ist Giant SyncDrive Pro2 (85 Nm, von Yamaha) mit Giant EnergyPak Smart 400 (Trance X E+ Elite) (400 Wh, integriert). Welche Akkus zum System passen: Giant SyncDrive.
